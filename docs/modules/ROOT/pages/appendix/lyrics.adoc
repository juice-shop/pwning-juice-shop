== Jingle ringtone (RTTTL)

The sung melody of the jingle (transposed three octaves up) as monophonic ringtone in
https://en.wikipedia.org/wiki/Ring_Tone_Transfer_Language[RTTTL] format to be played e.g. by the
https://github.com/neverfa11ing/FlipperMusicRTTTL[Flipper Zero Music Player].
Copy the line into a txt file under `apps_data/music_player` on the Flipper SD card.
